# Проверка первой версии — 5 ноября 2026

Обновление повседневных сценариев: прошли 69 автоматических проверок, включая учёт времени по дням, частичные отметки и их отмену после навигации, фактическое время, разовый бюджет на сегодня, сроки к уроку, редактирование без дубликатов, конфликт одновременных правок, быстрый ввод и повтор. На копии настоящей базы проверено сохранение исходных классов, участников, заданий и отметок. Старые сроки не сдвигаются, историческим отметкам не приписывается вымышленный день выполнения. Новые таблицы добавляются без изменения исходной структуры заданий.

Динамические данные: новые проверки сравнивают фактические байты PNG при изменении минут, текста задания, предмета, срока и свободного времени. Проверены значения «было + новое = итог», оценка и фактическое время, реальные записи текущей страницы заданий и обновление кеша медиа при изменении данных.

Проверка обновления с данными: отрисованы и просмотрены 10 актуальных примеров. В настоящий MAX доставлена обновлённая карточка с двумя существующими заданиями владельца; текст и минуты карточки сверены с базой, пользовательские данные не менялись. Очереди отправки и удаления пусты, новый фоновый процесс работает с прежней базой.

- Python 3.11.0, Windows.
- Основные и новые сценарии проверяются: `python -m unittest discover -s tests -v`.
- В тесте планировщика дополнительно проверены 100 воспроизводимых случайных наборов: дневные ограничения соблюдаются, работа не назначается после дедлайна, минуты не исчезают.
- Локальный сценарий трёх ролей `python demo_scenario.py` прошёл: создание класса, приглашения, публикация, предупреждение о перегрузе, недельный план, персональная отметка выполнения.
- Реальный MAX API принял токен через `GET /me`; секрет и полный ответ не выводились.
- Webhook-подписок на момент подключения не было.
- Бот запущен на этом компьютере в фоне. MAX-события принимаются, ответы доставляются.
- Пользователь подтвердил в MAX создание класса и получение кодов.
- Пользователь подтвердил в MAX предупреждение «Высокая нагрузка» до публикации задания.

Обновление интерфейса: отрисованы и визуально проверены 8 примеров карточек. Проверены календарь с переключением месяцев, выбор даты без ввода года, короткие русские даты, выбор доступного времени кнопками, постраничный план и список заданий. Тесты подтверждают, что старая карточка удаляется после доставки новой, а при сбое отправки остаётся на месте. Загрузка PNG на реальный медиа-сервер MAX прошла успешно.

Проверка в настоящем MAX: в диалог владельца доставлены графики нагрузки и обновлённое главное меню; после доставки меню предыдущая графическая карточка успешно удалена через API. Очереди отправки и удаления пусты. Обновлённый фоновый процесс запущен с прежней базой; перед обновлением сохранена резервная копия.

Локальные тесты не заменяют проверку всех ролей с реальных аккаунтов MAX. Полный проход учитель → ученик с двумя аккаунтами, постоянный сервер и production Webhook ещё не проверены и не включены в подтверждённый результат. Docker в этой среде отсутствует, контейнер не запускался.

Используется проверенный HTTPS-адрес `platform-api.max.ru`; новый адрес `platform-api2.max.ru` в этой среде требует настройки доверенных сертификатов. Проверка TLS не отключалась.

Архив проекта не содержит `.env`, базу данных, логи или токен. Рабочая конфигурация и данные остаются только в локальной папке запуска.
